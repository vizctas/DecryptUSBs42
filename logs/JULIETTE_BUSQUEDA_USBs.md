## 💡 **LECCIONES DE SUPERVIVENCIA DE JULIETTE:**

### **✅ Estrategias Exitosas:**
1. **Reconocimiento primero:** Siempre observa antes de entrar
2. **Diversión táctica:** Usa ruido para desviar zombies
3. **Rutas de escape:** Siempre tiene plan B y C
4. **Búsqueda sistemática:** Revisa todas las habitaciones
5. **Extracción limpia:** Cubre huellas, evita persecución

### **❌ Errores a Evitar:**
1. **Ruido innecesario:** Disparos atraen hordas
2. **Sobrestimación:** No subestimar edificios grandes
3. **Falta de preparación:** Siempre llevar suministros
4. **Codicia:** No arriesgar todo por loot extra
5. **Fatiga:** No explorar cuando estás cansado

### **🧟 Tácticas de Combate Probadas:**
- **Cuchillo para sigilo** (bajo ruido, bajo riesgo)
- **Pistola para defensa** (rápida, precisa)
- **Molotov para emergencias** (limpia grupos, crea caos)
- **Cobertura constante** (usa muebles, paredes)
- **Movimiento impredecible** (cambia dirección frecuentemente)
